# LPA-RadioSkyMapper

Данный репозиторий содержит скрипты обработки архивных данных радиотелескопа БСА (Большая Синфазная Антенна). Он ведёт наблюдения на на частоте 110 МГц в режиме пассажного инструмента, сканируя небо вдоль небесного меридиана.

- `mapping.py` строит карты неба для указанного интервала дат. Проводит калибровку сырых временных рядов, ресемплинг, приводит координатную сетку к эпохе J2000.
- `stacking.py` проводит статистику карт и сохраняет "карты аномалий" для поиска транзиентов.

Запуск предполагается на сервере Пущинской радиоастрономической обсерватории АКЦ ФИАН.
Результаты сохраняются в цветные PNG изображения для визуального анализа и в NumPy массивы для дальнейшей обработки.


## Использование (CLI)

Тестировалось на Linux. Рекомендуется установить менеджер пакетов `uv`.

**Установка:**
```bash
git clone https://github.com/Askaniy/LPA-RadioSkyMapper.git
cd LPA-RadioSkyMapper
uv sync
```

**Базовый синтаксис:**
```bash
uv run mapping.py <DATE1> <DATE2> [OPTIONS]
uv run stacking.py <DATE1> <DATE2> [OPTIONS]
```

**Аргументы:**
* `DATE1` (обязательно): Дата начала интервала наблюдений в формате `ГГГГ-ММ-ДД`.
* `DATE2` (обязательно): Дата окончания в формате `ГГГГ-ММ-ДД`.
* `--data_path` (опционально): Путь к архивным данным (по умолчанию: `/bsa_b/`)
* `--workers` (опционально): Количество рабочих процессов для чтения данных (по умолчанию: 12)

**Пример запуска:**
```bash
uv run mapping.py 2013-10-11 2026-07-01
uv run stacking.py 2013-10-11 2016-05-26
```


## Технические детали

### Картографическая система

Используется простая цилиндрическая проекция (3600×1800 пикселей).
Охват по склонениям: от −9.25° до +55.25° (всего 64.5°).
Охват по прямым восхождениям: от 360° до 0°.

**Координаты в пиксели:**

$$x = 3599.5 - \alpha \cdot 10$$

$$Y = (90^\circ - \delta) \cdot 10 - 0.5$$

$$y = (55.3^\circ - \delta) \cdot 10 - 0.5$$

**Пиксели в координаты:**

$$\alpha = \frac{3599.5 - x}{10}$$

$$\delta = 90^\circ - \frac{Y + 0.5}{10} = 55.3^\circ - \frac{y + 0.5}{10}$$

**Сопоставления по долготе ($\alpha$):**
| $x$ | $\alpha$ |
| :--- | :--- |
| 0 | 359.95 |
| 3599 | 0.05 |

**Сопоставления по широте ($\delta$):**
| $Y$ | $y$ | $\delta$ |
| :--- | :--- | :--- |
| 0 | | $89.95^\circ$ |
| 347 | 0 | $55.25^\circ$ |
| 992 | 644 | $-9.25^\circ$ |
| 1799 | | $-89.95^\circ$ |


### Архитектура временной обработки

БСА сохраняет наблюдения ежечасно в файлы формата PNTR, отдельно для каждого из трёх регистраторов.
Скрипт использует многопроцессорную архитектуру с разделяемой памятью (`SharedMemory`), заполняемой и считываемой циклически:
1. **Регистраторные рабочие процессы**: до 12 процессов, задача которых — обработать конкретный час для конкретного регистратора и записать результат в общий буфер. Перед записью в кольцевой буфер, прочитанные данные сжимаются в 27 раз медианной фильтрацией. В процессах измеряются калибровочные ступеньки, прерывающие поток данных каждые 4 часа, и записываются в собственный блок разделяемой памяти. Калибровочные ступеньки удаляются из данных после считывания.
2. **Картографирующие рабочие процессы**: 4 процесса, собирающие накопленные данные из общего буфера, бинирующие их для сетки пикселей (со сжатием примерно в 5 раз), выполняющие интерполяцию по склонениям (Cubic Spline), применяющие поворот координат к эпохе J2000, сжимающие в 4 раза и генерирующие финальное изображение карты. Триггер начала генерации карты — наличие двух калибровочных ступенек до и после интервала наблюдений карты, что обеспечивает качественную интерполяцию калибровочных данных.
3. **Главный процесс**: Оркестратор, который распределяет задачи порциями по 4 часа для обеспечения максимальной загрузки процессора.

Границы карт определяются по времени кульминации точки ($\alpha=0$, $\delta=0$), вычисляемую библиотекой `astroplan` с учётом модели вращения Земли.
При сохранении, в именах файлов указывается модифицированная юлианская дата (MJD) окончания интервала карты, которая соответствует левому краю.
То есть, время на карте вычисляется как T = MJD + α_источника.
Пять знаков после запятой обеспечивает избыточную точность (1 с), в то время как шаг сетки составляет примерно 24 с.


### Пространственно-спектральная обработка

БСА проводит постоянный мониторинг неба в 128 лучах, неравномерно распределённых по склонениям, и каждый из лучей разбивается в пучки по 6 частотных каналов от 109.21 до 111.29 МГц.
Ближе к границам обзора расщепление достаточно сильное, чтобы частотные каналы разных лучей перекрывали друг друга по склонениям.
Поэтому при картографировании не получится пренебрегать спектральным разложением в лучах.
Напротив, эффект используется для повышения разрешения по оси склонений: карты для разных каналов обрабатываются индивидуально.
В таком виде они сохраняются в NumPy массивы, а для визуализации шесть каналов сжимаются до трёх (RGB):

```math
\mathbf{v}_{\text{RGB}}
=
\frac{1}{6} 
\begin{bmatrix}
    3 & 2 & 1 & 0 & 0 & 0 \\
    0 & 1 & 2 & 2 & 1 & 0 \\
    0 & 0 & 0 & 1 & 2 & 3
\end{bmatrix}
\cdot
\mathbf{v}_{6\text{ channels}}
```

Данная техника называется "обработкой в ложных цветах" и помогает выделять артефакты и другие ошибки в данных.
На получаемой карте реальные радиоисточники чаще всего имеют нейтральный, серый цвет из-за узости спектрального диапазона БСА.
В свою очередь, многие наблюдательные артефакты имеют "цвет", то есть, ненастоящий поток зачастую не повторяется в разных каналах.


### Карты аномалий

Для облегчения визуального поиска транзиентов были построены "карты аномалий", отношения наблюдаемого потока к эталонному: $r = F_obs / F_ref$.
Чтобы различать усиления и ослабления потока, серый цвет ($c = 255 / 2$) соответствует неизменному потоку.
Установим логарифмический масштаб и границы различимых $r$: $r_{max} = 5$, $r_{min} = 1 / r_{max}$. Тогда формула, связывающая яркость карт аномалий $c$ и отношение потоков $r$:
```math
c = \frac{255}{2} \left(1 + \log_{5}{r} \right)
```

Соответственно, по карте можно оценить r:
```math
r = 5^{\frac{2 \, c}{255} - 1}
```


### Калибровка потока

Каждые 4 часа во временной ряд наблюдений БСА записывается шумовой сигнал (калибровочная ступенька) с фиксированной яркостной температурой 2400 К с точностью 2–3% (L) и яркостным уровнем "закрытого затвора" (D).
Показания интерполируются кубическим сплайном для калибровки временного ряда по формуле:
```math
F_{obs} = \frac{F_{raw} - D}{L - D}
```

Профиль ступеньки в индексах точек ряда выглядит следующим образом:
- с 3006 по 3008 затвор закрывается
- с 3008 по 3056 затвор закрыт
- с 3056 по 3058 калибровочный источник загорается
- с 3058 по 3106 калибровочный источник горит
- с 3106 по 3108 калибровочный источник затухает
- с 3108 по 3156 затвор закрыт
- с 3156 по 3158 затвор открывается
